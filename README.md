# เครื่องคำนวณจุดศูนย์ถ่วง (CG Calculator)

เว็บแอปสำหรับคำนวณตำแหน่งจุดศูนย์ถ่วง (Center of Gravity) ของรถยนต์ (4 ล้อ) และมอเตอร์ไซค์ (2 ล้อ)
โดยใช้วิธีชั่งน้ำหนักแต่ละล้อ (static weighing) ร่วมกับวิธียกปลายด้านหนึ่งขึ้น (tilt-table method)
สำหรับหาความสูงของ CG

เป็นไฟล์ HTML เดี่ยว (self-contained) ไม่ต้องติดตั้งอะไรเพิ่ม เปิดใช้งานได้ทันทีในเบราว์เซอร์

## สิ่งที่คำนวณได้

- ตำแหน่ง CG ตามยาว (ระยะจากเพลาหน้า / เพลาหลัง)
- ตำแหน่ง CG ตามขวาง — เฉพาะโหมดรถยนต์ (ระยะจากด้านซ้าย / ด้านขวา)
- ความสูงของ CG จากพื้น (จากการทดสอบยกปลายด้านหนึ่งขึ้น)
- แผนภาพประกอบมุมมองด้านบนและด้านข้าง พร้อมเส้น dimension ที่อัปเดตตามค่าที่กรอกแบบเรียลไทม์
- ที่มาของสมการที่ใช้คำนวณทั้งหมด

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (ดับเบิลคลิก หรือเปิดผ่าน GitHub Pages)
2. เลือกโหมด รถยนต์ หรือ มอเตอร์ไซค์
3. กรอกน้ำหนักแต่ละล้อจากการชั่งท่าราบ และระยะฐานล้อ (L)
4. กรอกผลจากการยกปลายด้านหนึ่งขึ้น (ความสูงที่ยก H และน้ำหนักฝั่งที่ยังอยู่บนพื้น)
5. อ่านผลลัพธ์และแผนภาพที่คำนวณให้อัตโนมัติ

## การนำขึ้น GitHub Pages

หลัง push โค้ดขึ้น repository แล้ว:

1. ไปที่ **Settings → Pages**
2. ในหัวข้อ **Build and deployment** เลือก Source เป็น `Deploy from a branch`
3. เลือก branch `main` และโฟลเดอร์ `/ (root)`
4. บันทึก แล้วรอสักครู่ เว็บจะขึ้นที่ `https://<username>.github.io/<repo-name>/`

## หมายเหตุ
